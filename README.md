# Созвон — свои видеозвонки без VPN

Видеозвонки в браузере: камера, микрофон, чат, демонстрация экрана, настройки звука и видео.
Работает на **вашем собственном сервере**, поэтому не зависит от заблокированных сервисов: участникам VPN не нужен,
нужен только браузер (Chrome, Яндекс Браузер, Edge, Firefox, Safari; на телефоне тоже).

## Что умеет
- Комнаты по ссылке (`https://ваш-домен/?room=название`), до 8 человек в комнате
- Камера и микрофон: включение/выключение, выбор устройства на лету, индикатор громкости
- Выбор динамиков/наушников и кнопка «Проверить звук» (Chrome, Edge, Яндекс)
- Звук: эхоподавление, шумоподавление, автоусиление
- Видео: 360p / 720p / 1080p, 15–30 кадров/с, зеркалирование своего видео
- Демонстрация экрана (окно, вкладка или весь экран), в том числе со звуком; режим «чёткость» для текста и кода или «плавность» для видео
- Чат с историей (кто зашёл позже, видит переписку), кликабельные ссылки, счётчик непрочитанных
- Подсветка говорящего, «поднять руку», закрепление плитки кликом, полноэкранный режим двойным кликом
- Горячие клавиши: **M** — микрофон, **V** — камера
- Настройки запоминаются в браузере

## Как это устроено
Видео и звук идут **напрямую между участниками** (WebRTC, шифрование DTLS-SRTP).
Сервер только знакомит участников друг с другом и пересылает чат. Если прямое соединение невозможно
(мобильный интернет, строгий NAT, корпоративная сеть), трафик идёт через ваш TURN-сервер (coturn).
Внешних сервисов нет, поэтому блокировки на них не влияют.

## Быстрый запуск на VPS (Docker)
Нужен VPS с Ubuntu (1 vCPU / 1 ГБ хватит) и домен.
Хостинг в РФ (Timeweb, Selectel, REG.RU и т. п.) — самый надёжный вариант без VPN.

1. В DNS домена добавьте A-запись `call.example.ru → IP сервера`.
2. Откройте порты в файрволе:
   ```
   sudo ufw allow 80,443/tcp
   sudo ufw allow 3478,5349/tcp
   sudo ufw allow 3478/udp
   sudo ufw allow 49160:49200/udp
   ```
3. Установите Docker и запустите:
   ```bash
   curl -fsSL https://get.docker.com | sh
   cd sozvon
   cp .env.example .env && nano .env      # домен, IP, секрет (openssl rand -hex 32)
   docker compose up -d --build
   ```
4. Откройте `https://call.example.ru`, введите имя и отправьте ссылку на комнату собеседникам.

> Первые 1–2 минуты coturn может перезапускаться: он ждёт, пока Caddy получит HTTPS-сертификат. Это нормально.

## Запуск без Docker
```bash
node server.js           # нужен Node.js 18+, зависимостей нет
```
Откройте http://localhost:3000. На своём компьютере камера работает и по http.
**Для доступа по сети нужен HTTPS**: без него браузер не даст доступ к камере и микрофону.
Поставьте перед приложением nginx или Caddy с сертификатом, а coturn установите отдельно (`apt install coturn`).
Пример systemd-юнита лежит в `deploy/sozvon.service`.

Переменные окружения сервера:

| Переменная | Что делает |
|---|---|
| `PORT` | порт (по умолчанию 3000) |
| `TURN_HOST` | домен/IP вашего coturn |
| `TURN_SECRET` | тот же секрет, что `static-auth-secret` в coturn |
| `TURN_TLS=1` | добавить TURN поверх TLS на 5349 (лучше проходит через фильтры) |
| `STUN_URLS` | внешние STUN через запятую; пусто — не использовать |
| `MAX_PEERS` | лимит людей в комнате |

Для nginx отключите буферизацию: `proxy_buffering off;` (`/events` — это поток Server-Sent Events).

## Если что-то не работает
- **Нет кнопки демонстрации** — мобильные браузеры не умеют показывать экран, это ограничение платформы.
- **Собеседника не видно, висит «Подключение…»** — не работает TURN. Проверьте, что открыты порты UDP 3478 и 49160–49200 и что `PUBLIC_IP` правильный.
  Проверка: https://webrtc.github.io/samples/src/content/peerconnection/trickle-ice/
- **Камера «занята»** — закройте другие приложения, которые используют камеру (Zoom, Telegram, OBS).
- **Больше 6–8 человек** — в этой архитектуре каждый отправляет видео каждому, поэтому на 8+ людей лучше
  переходить на SFU (LiveKit, mediasoup). Для команд и созвонов 2–6 человек текущей схемы достаточно.
